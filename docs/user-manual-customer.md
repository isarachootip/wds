## วิธีติดตามสถานะของคุณ

### LINE OA
1. เพิ่มเพื่อน LINE OA: @WDS (หรือสแกน QR Code)
2. ส่งข้อความหาเราได้เลย เจ้าหน้าที่จะติดต่อกลับ
3. ระบบจะส่งการแจ้งเตือนสำคัญผ่าน LINE:
   - ใบเสนอราคา (พร้อมลิงก์ยืนยัน)
   - นัดหมายช่างเข้าบ้าน
   - ช่างถึงหน้างาน
   - งานเสร็จ
   - ยืนยันรับเงิน
   - ของกำลังส่ง
   - ส่งมอบสำเร็จ

## ยืนยันใบเสนอราคา

1. รับ LINE → กดลิงก์ "ดู/ยืนยัน ใบเสนอราคา"
2. ตรวจสอบรายการและราคา
3. กด **ยืนยัน** หรือ **ปฏิเสธ** (ระบุเหตุผล)
4. เมื่อยืนยัน ระบบสร้าง Order ให้อัตโนมัติ

---

## ชำระเงิน

1. โอนเงินตามยอดในใบ QT
2. เข้าลิงก์ติดตาม Order (รับจาก LINE หรือเจ้าหน้าที่)
3. กด **แนบสลิปโอนเงิน**
4. ถ่ายรูปสลิปหรือเลือกจาก Gallery
5. กรอกจำนวนเงิน → กด **ส่งสลิป**
6. ทีมบัญชียืนยันภายใน 1-2 ชั่วโมง (เวลาทำการ)

---

## ติดตามสถานะ Order

เข้าลิงก์ที่ได้รับจาก LINE หรือ: **wds.yourdomain.com/portal/orders/[token]**

สถานะต่างๆ:
| สถานะ | หมายความว่า |
|---|---|
| รับ Order แล้ว | ระบบรับ Order ของคุณแล้ว |
| ตรวจสอบเครดิต | ทีมการเงินกำลังตรวจสอบ |
| รอชำระเงิน | กรุณาชำระและแนบสลิป |
| ชำระแล้ว | รับเงินครบแล้ว |
| เตรียมสินค้า | คลังกำลังเตรียมสินค้า |
| กำลังจัดส่ง | สินค้าอยู่ระหว่างขนส่ง |
| ส่งมอบแล้ว | ส่งถึงมือคุณแล้ว |
