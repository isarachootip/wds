## 1. เริ่มต้นใช้งาน

### เข้าสู่ระบบ
1. เปิด Chrome หรือ Edge บนคอมพิวเตอร์
2. ไปที่ https://wds.yourdomain.com
3. กรอก Email และ Password ที่ได้รับจาก Admin
4. กด **เข้าสู่ระบบ** → ระบบจะพาไปที่ Dashboard โดยอัตโนมัติ

---

## 2. Lead & CRM (สำหรับ Sales)

### เพิ่ม Lead ใหม่
**ไปที่ /wds/leads → กด "+ สร้าง Lead"**

| ฟิลด์ | รายละเอียด |
|---|---|
| ชื่อลูกค้า | ชื่อ-นามสกุลหรือชื่อบริษัท |
| แหล่งที่มา | LINE / โทรศัพท์ / หน้าร้าน / อื่นๆ |
| สถานะ | ระบบตั้งเป็น "ใหม่" อัตโนมัติ |
| ผู้รับผิดชอบ | เลือก Sales ที่ดูแล Lead นี้ |
| งบประมาณ | ประมาณการงบลูกค้า |

### ติดตาม Lead (Follow-up)
- ไปที่ **Pipeline View** (/wds/pipeline) เพื่อดูแบบ Kanban
- ลาก Lead ข้ามคอลัมน์เพื่อเปลี่ยนสถานะ
- กด **+ Follow-up** เพื่อตั้งเตือนโทรหาลูกค้า

### ขอสำรวจหน้างาน
1. เปิด Lead → กด **ขอสำรวจหน้างาน**
2. กรอกที่อยู่ไซต์ (ค้นจาก Google Maps ได้)
3. ระบุวัตถุประสงค์และขอบเขตงาน
4. กด **ส่งคำขอ** → Coordinator จะได้รับแจ้งเตือน

---

## 3. Appointment & Site Visit (สำหรับ Coordinator)

### อนุมัตินัดหมาย
1. ไปที่ **/wds/appointments** → เห็น badge แดงบน "รออนุมัติ"
2. คลิกนัดหมายที่ต้องการ → ตรวจสอบทีมและวันที่
3. กด **อนุมัติ** หรือ **ปฏิเสธ** (ระบุเหตุผล)
4. ลูกค้าจะได้รับ LINE แจ้งเตือนอัตโนมัติ

### Calendar View
- /wds/appointments/calendar แสดงตารางงานรายสัปดาห์
- สีต่างๆ แทนทีมช่าง

---

## 4. ใบเสนอราคา (สำหรับ Sales/Coordinator)

### สร้าง QT ใหม่
**ไปที่ /wds/quotations/new**
1. เลือกลูกค้าหรือ Lead
2. เพิ่มสินค้าจากรายการ หรือพิมพ์รายการเอง
3. ตั้ง Discount และ VAT
4. กด **บันทึก Draft** หรือ **ส่ง QT** ทันที

### ส่ง QT ให้ลูกค้า
- กด **ส่ง QT** → ระบบส่ง Flex Message ผ่าน LINE โดยอัตโนมัติ
- ลูกค้าเปิดลิงก์ → ยืนยัน/ปฏิเสธได้เลย
- เมื่อลูกค้ายืนยัน ระบบสร้าง Order อัตโนมัติ

---

## 5. Order & Credit (สำหรับ Accounting)

### ตรวจสอบ Credit
- Order ที่ติด **Credit Hold** จะปรากฎใน **/wds/credit**
- ตรวจสอบเหตุผล (ยอดเกิน, ค้างชำระ, ลูกค้าใหม่)
- กด **อนุมัติ Override** เพื่อปล่อย Order

### ยืนยันการชำระ
1. ไปที่ **/wds/payments**
2. ดูสลิปที่แนบมา (กด "ดูสลิป")
3. กด **✅ ยืนยันรับชำระ** หรือ **❌ ปฏิเสธ** (ระบุเหตุผล)
4. เมื่อยอดครบ ระบบเปลี่ยน Order → "คลังเตรียม" อัตโนมัติ

---

## 6. Delivery (สำหรับ Warehouse/Coordinator)

### จัดตารางส่ง
1. ไปที่ **/wds/deliveries** → กด **+ จัดส่ง**
2. เลือก Driver และรถ
3. ระบุวันที่นัดส่ง
4. Driver จะเห็นงานใน app มือถือทันที

### ติดตามสถานะ
- สีเขียว = ส่งสำเร็จ
- สีส้ม = กำลังส่ง
- สีแดง = ส่งไม่สำเร็จ (ตรวจ attempt)

## คำถามที่พบบ่อย

**Q: Lead หายไปไหน?**
A: ตรวจ filter "สถานะ" ที่หน้า /wds/leads — อาจถูก filter อยู่

**Q: ลูกค้าบอกว่าไม่ได้รับ QT ใน LINE?**
A: ตรวจ LINE channel ว่า customer block LINE OA หรือไม่ — ให้ส่ง link โดยตรงแทน

**Q: Order ติด Credit Hold แต่ลูกค้าไม่ได้ค้างชำระ?**
A: อาจเป็นลูกค้าใหม่ที่ยอดเกิน 50,000 บาท — Accounting อนุมัติได้
