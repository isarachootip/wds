## 1. เปิด App

1. เปิด **Chrome บนมือถือ** (Android/iPhone)
2. ไปที่ https://wds.yourdomain.com
3. Login ด้วย Account ที่ได้รับ
4. ระบบพาไปที่ **/visit/dashboard** อัตโนมัติ

> 💡 **แนะนำ**: Add to Home Screen เพื่อใช้เหมือน app จริง
> iPhone: Safari → Share → Add to Home Screen
> Android: Chrome → Menu → Add to Home Screen

## 2. ดูงานประจำวัน

**ไปที่ /visit/deliveries**

- แสดงเฉพาะงานส่งวันนี้
- กดงานเพื่อดูรายละเอียด (ที่อยู่, รายการสินค้า)
- สถานะ: 📅 นัดหมาย → 📦 กำลังเตรียม → 🚚 กำลังส่ง → ✅ ส่งแล้ว

---

## 3. ขั้นตอนการทำงาน

### เตรียมสินค้า
กด **📦 เริ่มเตรียมสินค้า** → สถานะเปลี่ยนเป็น "กำลังเตรียม"

### ออกเดินทาง
กด **🚚 ออกเดินทางแล้ว** → แจ้งระบบว่าออกจาก warehouse แล้ว

### ส่งสำเร็จ — ขั้นตอนสำคัญ
1. กด **✅ ส่งสำเร็จ + ถ่ายรูป POD**
2. **ถ่ายรูปหลักฐานการส่ง (POD)** — บังคับ ถ้าไม่มีรูปปิดงานไม่ได้
3. กรอก **ชื่อผู้รับของ** — บังคับ
4. กด **ยืนยันส่งสำเร็จ**

### ส่งไม่สำเร็จ
กด **❌ ส่งไม่สำเร็จ** → ระบุเหตุผล (ไม่มีคนรับ/ที่อยู่ผิด/ลูกค้าเลื่อน)

> ⚠️ **หมายเหตุ**: หากส่งไม่สำเร็จ 3 ครั้ง ระบบจะแจ้ง Manager อัตโนมัติ

## 4. งานหน้าไซต์ (Site Job)

- **Check-in**: กด Check-in ที่หน้างาน — ระบบบันทึก GPS
  - ถ้า GPS ห่างจากไซต์เกิน 500 เมตร จะมีคำเตือน (ยังกด check-in ได้แต่ถูกบันทึก)
- **บันทึกงาน**: เพิ่มรายการงาน, รูปถ่าย before/during/after
- **Check-out**: สรุปงาน + ลายเซ็นลูกค้า

## 5. ปัญหาที่พบบ่อย

**Q: กด Check-in แล้วบอกอยู่นอกพื้นที่?**
A: ให้กด Check-in ต่อได้ แต่ระบบจะบันทึกว่า flagged — แจ้งหัวหน้าทีมทราบ

**Q: ถ่ายรูป POD แล้วระบบไม่ยอมรับ?**
A: ไฟล์รูปต้องไม่เกิน 10MB ลองถ่ายใหม่หรือลดขนาดรูป

**Q: แอปช้า / หน้าขาว?**
A: ปิดแล้วเปิดใหม่ ตรวจสอบ internet — ระบบทำงานออนไลน์เท่านั้น
